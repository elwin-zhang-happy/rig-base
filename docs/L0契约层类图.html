UML class · Rig L0

Rig L0 契约层 · UML 类图

L0 是 Rig 可序列化、无 IO 的契约层：消息与会话是数据，Operation 与 Wire 是纯函数契约，Tool 是行为契约。两张图共 10 个类，重复实现（40 余个 wire、十余个 transport、十余个向量库后端）一律收拢为省略号，只展开代表行为的那一份。

本系列：L0 契约 · L1 调用 · L2 执行 · L3 编排 · L4 应用 · L5 宿主 · 横切面

L0-1 · 调用契约：一次调用经过谁

Wire 绑定一种 Operation；Completion 操作把 Request 绑定为 CompletionRequest、Response 绑定为 CompletionResponse。请求带走消息与工具定义，回复带回内容块与用量。

读法：Wire 绑定一种 Operation（一对多，一个操作对应 40 余个 wire 实现）；Completion 把 Request 绑定为 CompletionRequest、Response 绑定为 CompletionResponse。收拢未画：Decoder（classify / decode，每个回复一个新的状态机）、Fold（absorb / finish）、Transport 与 Model / DynModel（L1 调用层，下一张图）；Usage 是 CompletionResponse 的一个字段（token 计数与费用），随回复一起返回，不单独成类。

L0-2 · 会话与工具：状态和能力在哪

Session 落盘多个 agent 的 Conversation；Conversation 拥有消息；Tool 是行为契约，向量库以 Tool 的形态被调用。

读法：Session 拥有多个 agent 的 Conversation（组合，中间经 SavedAgent 落盘）；Conversation 拥有消息（组合）；工具调用与工具结果以消息块的形式在会话里流转。VectorStoreIndex 被 blanket 实现为 Tool（search_vector_store），十余个向量库后端共用这一条，不必手写工具适配。收拢未画：ToolDefinition（发给模型的名称加 schema）与 ToolContext（工具详图）；SessionStore（日志存取）与 AgentRun（L2 执行，下一张图）。

Rig L0 · UML class · 数字口径：wire 实现数与操作数取自《调用契约》的盘点（含测试替身）；类成员与签名取自当前工作树 rig-core / rig-memory。重复实现收拢为省略号，详见各图注。
