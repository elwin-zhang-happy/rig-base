Rig L2 执行层 · UML 类图

L2 回答一个执行单元如何推进：Agent 装配默认，AgentRunner 驾驶无 IO 的 AgentRun 状态机，TurnPolicy 按轮落门，AgentHook 在一组 on_ 回调点上转向。两张图 11 个类，全部住在 rig-agent。

本系列：L0 契约 · L1 调用 · L2 执行 · L3 编排 · L4 应用 · L5 宿主 · 横切面 · 总览

L2-1 · 推进链：装配、启动、驾驶、转向

AgentBuilder 一次性装配模型、工具与路由；Agent 每次 prompt 产出一个 AgentRunner；Runner 叠加 per-run 覆盖，沿同一条驱动循环推进；AgentHook 只看只改，不拥有状态。

读法：Builder 装配，Agent 启动，Runner 驾驶，Hook 转向，RunSpec 管预算与输出。Runner 的 per-run 覆盖（max_turns、model、preamble 等几十个选项）不回写 Agent；run() 与 stream() 共用同一条驱动循环 engine::drive_agent。收拢未画：HookStack 与各回调的事件和动作类型；OutputMode 与 UnhandledInvalidToolCall；Extractor 与 TypedRun（循环之上，非循环之中）。Runner 驾驶的 AgentRun 状态机见 L2-2。

L2-2 · 状态机：无 IO 的推进协议

AgentRun 是可序列化的状态机：next_step 说要什么，driver 做完经 model_response 或 answer 反馈回来；TurnPolicy 决定本轮哪些工具可执行；答复经 answer 或 answer_all 生效。

读法：driver 匹配 AgentRunStep 行动：调模型、答工具、或结束；畸形调用永不执行，只能按 InvalidToolCallAction 处置；门没有独立类型，本轮归 TurnPolicy，跨轮转向归 Hook（见 L2-1）。TurnPolicy 由 RunSpec 派生；流式与 unary 共用同一状态机，StreamedTurn 只是另一种投喂。收拢未画：RunState、CommittedLog 与 ToolBatch 等 Run 内部件；RetryRequest 与修复路径。
