Rig 横切面 · UML 类图

横切面不是层：持久化面与可观测面被各层调用，但只依赖 L0。持久化记住发生过什么（会话日志与 effect 日志两套），观测回答正在发生什么（用量记进 span，轨迹走 Witness）。三张图 12 个类，另有一个外部引用（tracing::Span）。

本系列：L0 契约 · L1 调用 · L2 执行 · L3 编排 · L4 应用 · L5 宿主 · 横切面 · 总览

P-1 · 会话面：日志是事实，会话是回放出来的像

Store 是追加写后端，有 DirStore 与 MemoryStore 两种实现；Session 经 read 读出、经 save 写回；SessionStore 与 SessionLog 把它们绑进 ECS。

读法：没有 SessionStore 就什么都不留；SessionLog 先攒后写进 Store 的日志；恢复走全量重读（Session::read）。收拢未画：SessionLog 的内部缓冲；LogRewrite；MemoryStore 与 DirStore 的各自细节。Session 的 agents 字段是 SavedAgent，见 L0-2 与 L3-1。

P-2 · effect 面：记下来，再放回去

EffectLogRecorder 把 EffectRecord 攒成 EffectLog；Checkpoint 是 effect 日志范围内的恢复点（状态加尾巴）；EffectLogReplayer 按 HandlerKey 把答过的答案再放回去。

读法：录制与回放是同一卷日志的两端：Recorder 只写，Replayer 只读，Checkpoint 从中间劈开接续。收拢未画：fixtures/effects 里的 golden 语料与 verify 套件；serve 的 RecordBuffer。

P-3 · 可观测面：用量进 span，轨迹走 Witness

Usage 是统一的 token 与费用事实；SpanBuilder 按 GenAI 语义开 span，SpanCombinator 把用量写上去；Witness 是给 driver 与宿主留的发射口。

读法：观测不经过 handler 表：span 直接交给 tracing，Witness 直接调 observe。Model 的 call_observed 与 stream_observed 把一次调用挂进 Observation。收拢未画：各 provider 的 record_* 落点；redact 与 adapter 的发射前清洗。缺席：没有找到指标注册表与导出器，用量只以数据与 span 字段存在。
