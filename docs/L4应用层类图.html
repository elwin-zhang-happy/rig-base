Rig L4 应用层 · UML 类图

L4 回答一次业务用例如何开始、恢复、观察：Agent::prompt 启动新的，Agent::resume 接回落盘的，AgentRunner 是活的句柄，观察靠事件流、RunEvents 与 Hook；模型与工具以 handler 的身份经 Handlers 表抵达 run。两张图 9 个类，另有一个跨页引用（AgentRun，详见 L2-2）。

本系列：L0 契约 · L1 调用 · L2 执行 · L3 编排 · L4 应用 · L5 宿主 · 横切面

L4-1 · 用例生命周期：开始、恢复、观察

prompt 开新的，resume 接回落盘的 AgentRun；Runner 是活的句柄，可等、可流、可拆；观察有三条路：MultiTurnStreamItem 事件、RunEvents 定界 feed、AgentHook 回调。

读法：开始与恢复是 Agent 的两个方法，句柄是 Runner，观察是事件加 feed 加回调，状态机本身住在 L2-2。RunEvents 定界 32 条（RUN_EVENTS_CAPACITY）。收拢未画：TypedRun 与 Extractor；HookStack；AgentRun 的内部数据（ModelTurn、CompletionCall 等）。

L4-2 · 服务边界：模型与工具以 handler 抵达

Serve 是分发边界：descriptor 自报家门，serve 干活；ErasedHandler 把它擦除后按 HandlerKey 注册进 Handlers 表；ModelAdapter 与 ToolAdapter 是两边的入适配。

读法：run 服务 effect 不直接调模型或工具，而是查 Handlers 表；表里的每一项都是 ErasedHandler；适配器负责把模型、工具、检索索引变成 Serve。收拢未画：ToolAdapter 与 RetrieveAdapter（与 ModelAdapter 同文件）；Intercept、Recorder 与 Layer 中间件。AgentRunner 经 Handlers 分发，Runner 详见 L2-1。
