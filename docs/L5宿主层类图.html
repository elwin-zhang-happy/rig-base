L5 回答谁发起、谁消费：发起是 rig launcher 二进制（读布局、认会话、传参数），消费只有终端、headless stdio、编辑器桥三面，加一种库嵌入。两张图 11 个类，另有一个跨页引用（Agent，详见 L4-1）。

本系列：L0 契约 · L1 调用 · L2 执行 · L3 编排 · L4 应用 · L5 宿主 · 横切面 · 总览

L5-1 · 启动：launcher 如何开一次 run

run 是 rig 二进制的入口循环：读 Home 布局，认领 session，把 Invocation 交给 agent 一侧；AgentDescription 是插件上报的 CLI 形状，launcher 照着它认命令。

读法：启动等于读布局、认会话、传参数三步；命令的形状由插件上报，launcher 只认不上报。收拢未画：Home 下的 session 与 staged 等目录；DescribedFlag；rig plugin、project、build 等管理命令。

L5-2 · 消费：谁看结果、谁嵌进去

消费只有三面：交互终端（TuiPlugin）、headless 的 stdio 驱动（PrintPlugin）、编辑器经 AcpPlugin 接入；ChatBotBuilder 是库嵌入形态，HelpersPlugin 把能力包成工具。

读法：三面消费加一种库嵌入；ChatBotBuilder 吃一个 Agent 吐一个终端聊天循环；HelpersPlugin 把能力包成工具。收拢未画：rig-basics 里其余非 front 插件；corpus 系列测试程序（证明内核用的，不是宿主）。缺席：没有找到 HTTP 服务、任务队列与 Web UI；provider 侧只有出向 HTTP。
