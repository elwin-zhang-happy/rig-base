本系列：L0 契约 · L1 调用 · L2 执行 · L3 编排 · L4 应用 · L5 宿主 · 横切面 · 总览

L3-1 · 生与走：agent 从哪来、消息往哪去

Agent 本体是个 marker 组件，身份、血缘与权限是挂在同一个 entity 上的组件；Spawner 是唯一的制造入口，ChildOf 与 Like 两种 origin 按来源 agent 继承配置；fork 只复制日志到轮次边界，跑起来就不回头。

读法：多 agent 就是多 entity：造出来（Spawner）、复制一份（ForkAgent）、投递消息（Deliver）、选中当前跟用户说话的那个（CurrentAgent）、落盘带着血缘（SavedAgent）。身份、血缘、工具权限是同一 entity 上的 AgentId、SpawnedBy 与 Spawned、ToolAccess 组件。收拢未画：Origin 的三种取值；TurnCall 之外的调用家族；Prepare、Review 与 Gate 各插件相位。缺席：没有 Branch 与 Join 式的节点类型，fork 不 join；没有找到等子 agent 的句柄。

L3-2 · 调度泵：七个阶段推着 Effect 走

Stage 是排进 AgentPass 的执行顺序，Update 里的 AgentLoop 反复执行它；Effect 是最小的异步工作单元，带着归属与血缘；Turn 把一次用户请求收成一集，Running 把工作扇到线程池上跑。

读法：RunPlugin 决定一次 run 何时算完（headless 等 Work::idle），Stage 依次经过到达、评审、提交、准入、准备、设门、启动，Effect 在阶段之间流转，Running 在线程池里完成它们。Turn 的 reply 字段指回 Effect。收拢未画：TurnCall 之外的调用家族；Effect 上的控制标记；各阶段的插件系统集。缺席：并行是自然长出来的，没有找到 barrier 与 fan-in 原语；TurnCall 之外没有声明式的分支。
